Data Model:
----------------------------------------------
config:       How should the machine operate?
state:        What is the machine doing?
measurements: What is the machine measuring?
events:       What has happened?
commands:     What should the machine do?
----------------------------------------------

During the build process, all aspects of this 
data model must be defined. The Builder ensures 
that the resulting machine definition adheres 
to the specified model and that all required 
information is provided consistently.

Bookkeeping command availability:
- enable/disable can lead to a chain that leads to an illegal state
  where a command is enabled when its not supposed to. When registering
  the command a predicate may be provided to determine if a command is 
  ultimately allowed to be executed, this way a wrong chain exposing
  a command when its supposed to be locked cannot happen.
